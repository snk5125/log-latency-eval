# `report/evidence/` — Run Evidence

Artifacts produced by the run harness and analyzer, mapping to claims in
[`../REPORT.md`](../REPORT.md) §8 (Evidence Index). Until the matrix is executed
(`PLAN.md` §8), any per-run subdirectories present are placeholders/dry-run
scaffolding; real measurement data appears only after a live run. Nothing here
is fabricated.

## What lands here

- **Run manifests** — one per run: `run_id`, scenario, agent, aggregator, EPS
  tier, warm-up/measurement window timestamps, resolved AMI IDs, and pinned
  Vector/Cribl versions. Written by `harness/orchestrator/run_matrix.py`. Run
  subdirectories are named by run ID:
  `s{1-4}-{vec|ce}-{vagg|cs}-{1k|5k|10k}-{YYYYMMDDTHHMMSSZ}` (`PLAN.md` §3).
- **Clock-assertion records** — chrony tracking offset (Linux) and
  `w32tm /query /status` stripchart bound (Windows), captured per run by
  `ansible/playbooks/assert-clocks.yml` to evidence the bounds in `PLAN.md`
  §5.3 (Linux < 1 ms; Windows < 5 ms).
- **Analyzer output** — per run × OS × hop statistics (mean, p50, p90, p99,
  max, stddev, count, loss rate) and raw-vs-batch-adjusted S3-hop columns,
  produced by `harness/analysis/analyze.py`. These populate `REPORT.md` §7.
- **Charts** (if generated by the analyzer) supporting the findings tables.

## What is gitignored (raw data — do NOT commit)

Per the repo `.gitignore`, raw run data is excluded because it is large and
carries live resource identifiers:

- `report/evidence/raw/` — raw per-event captures
- `report/evidence/*.jsonl` — raw event streams
- `report/evidence/*.csv.gz` — compressed raw stats dumps

**Committed (retained):** summarized/aggregated stats, run manifests, and
clock-assertion records — the minimum needed to substantiate `REPORT.md`
without republishing raw event data or live identifiers. When citing evidence
in `REPORT.md` §8, reference only artifacts that actually exist here.
